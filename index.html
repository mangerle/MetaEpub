关于 MetaEpub
📚
MetaEpub
v0.2.3

MetaEpub 是一款轻量、现代化的 EPUB 电子书元数据编辑器。支持便捷修改书名、作者、语言、出版商、出版日期、描述信息与标识符，并支持在线替换封面与离线导出打包。

Tauri v2 Rust JavaScript Vite
开源项目： github.com/mangerle/MetaEpub
运行环境： Tauri 桌面客户端 (Windows / macOS / Linux)
